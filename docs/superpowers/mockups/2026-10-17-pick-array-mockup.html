선택 배열 생성기 · 팝업 편집안 (구현 참조본)

변수 열(실제 폭 210px)에는 요약만 두고, 편집은 팝업에서 합니다. 팝업에서 고친 값은 적용을 눌러야 시나리오에 들어가고, 취소·ESC·바깥 클릭은 버립니다. 팝업을 닫으면 변수 패널이 어떻게 보이는지 확인할 수 있습니다.

길이 예시로 채우기
스텝 흐름 · 상세 (목업)
정리된 규칙
  • 변수 패널: 이름 · 선택 배열 배지 · 요약 한 줄 · 예시 한 줄 · 편집 버튼. 행을 펼쳐도 인라인 편집기는 없습니다.
  • 팝업에선 텍스트 입력과 칸 그리드가 함께 보이고 항상 같은 상태입니다. 입력칸이 비면 "후보 없음" 오류이고, 적용 버튼이 잠깁니다.
  • 전체 자리가 후보일 땐 1-30처럼 전체 범위가 적힙니다. 이때 길이를 바꾸면 후보도 새 전체 범위를 따라갑니다.
  • 칸 클릭 = 켜기/끄기, Shift+클릭 = 범위. 번호는 1부터. 그리드는 높이 상한 안에서 세로로만 스크롤됩니다.
  • 값 형식은 기본 접힘(true / false). 프리셋 4종 또는 직접 입력. 직접 입력에선 true·false·null·숫자는 그 타입으로, 나머지는 문자열로.
  • 미정의 변수가 JSON 바디에서 "{{x:json}}"로 쓰이면 배열로 추가가 보입니다(목업의 seats 행은 시연용으로 flags 팝업을 엽니다).
