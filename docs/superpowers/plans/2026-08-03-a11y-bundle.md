**Goal:** 산재한 a11y 소형 결함 7건(US 5개)을 한 슬라이스로 해소 — 폼 힌트 SR 연결/중복 낭독 제거·접기 토글 aria-controls·배너 낭독 순서·heading 오염·버전 배지 대비/접근명.

**Tech Stack:** React 18 + RTL/vitest(jsdom) + Tailwind. spec: `docs/superpowers/specs/2026-08-03-a11y-bundle-design.md` (clean APPROVE, 커밋 `5577a0aa`).
