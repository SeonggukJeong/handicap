정할 것

Q1. 환경 변수 값을 화면에 보일까?벽 모니터라 토큰이 지나가는 사람에게 보일 수 있습니다. 추천: 전부 기본 가림(••••••••), v로 이 화면에서만 잠깐 보기, 입력줄엔 고치는 값만. 대안: 이름에 TOKEN·KEY·SECRET·PASSWORD·AUTH가 든 것만 가림(BASE_URL 같은 주소는 바로 보임).
Q2. 백업(.bak)은 언제 덮어쓸까?값을 고칠 때마다 저장하므로, 저장마다 .bak을 덮으면 백업은 "바로 전 상태" 하나뿐이고 GUI에서 받은 원본은 두 번째 저장에서 사라집니다. 추천: 원본 백업 하나 + 직전 백업 하나 — TUI가 처음 저장할 때 board.json.orig.bak가 없으면 원본을 그 이름으로 남기고(이후 안 덮음), 매 저장은 board.json.bak(직전). 대안: spec 그대로 .bak 하나(매번 덮음).
Q3. 값 입력 중 자리 비움(5분)이면?1b 규칙대로 모니터로 돌아가고, 입력 중이던 값은 저장하지 않고 버립니다(추천). 이미 저장한 값은 그대로.
Q4. 칸 설정에서 마우스추천: 줄 클릭 = 고르기, 같은 줄 다시 클릭 = Enter. 입력줄·목록은 키보드만.
