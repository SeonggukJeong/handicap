# 운영실 모니터 개선 (ops-monitor-polish) — 브레인스토밍 결정 원천 (2026-10-28)

> **이 파일이 1차·2차 슬라이스 spec의 결정 원천이다.** spec/plan/구현이 여기와 다르면 여기가 이긴다. 바꾸려면 사용자 재가 후 이 파일을 먼저 고친다.
> 표기: `[사용자]` = 사용자가 말한 것 · `[Claude]` = Claude 판단(사용자에게 제시, 이의 없음/승인).
> 목업: `01-shown-values-ABC.html`(② 시안 A/B/C — **C 채택** 근거) · `02-split-stats-chosen.html`(② **채택안 = 1번 보드** "반반 + 평균·최대", 2번 보드는 비교용) · `03-editor-collapse-nav.html`(⑥ 채택, 2차). 목업은 실제 화면과 같은 cqw 비율 공식으로 그렸지만 **배치·정보 구성의 정본**이고 글자 크기·간격 정본은 ①a spec §7.3 규칙이다(①b와 동일 원칙). 목업에 없는 화면을 새로 만들지 않는다.

## 사용자 원 요청 (2026-10-28, 원문)

1. 응답 항목 추출 여러번 가능한데, AND, OR 조건이 없음. 범위 지정, 포함값 여러개 지정 등에 사용할 수 있도록 AND, OR 조건 필요.
2. 추출한 항목 중 사용자가 선택한 항목은 정상 판정시에도 보이길 원함
3. JSON 응답에 큰 따옴표(") 앞 이스케이프문자(\)가 있는 경우, JSON으로 인식하지 못해서 추출도 불가한 문제가 있음.
4. 모니터 화면 막대그래프가 왼쪽부터 채우는데, 사람의 인식 상 오른쪽부터 채우면서 왼쪽으로 밀리는게 맞아보임.
5. 추출 항목의 조건을 지정할 때, 한국어 문구가 어색해서 판정 값 조건 정할때 혼란스러움.
6. 모니터 설정 화면에서 칸이 많으면, 한눈에 파악하기가 어려움 접었을 때 칸 이름이 보이고 오른쪽에는 쫓아다니는 네비게이션을 추가 하던가 했으면 좋겠음.
7. 모니터 히스토리 상에 보이는 막대그래프 구간 만큼 만이라도 요청과 응답기록을 확인할 수 있으면 좋겠음.
