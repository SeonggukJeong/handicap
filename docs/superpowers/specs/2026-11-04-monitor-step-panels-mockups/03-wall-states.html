전시 화면 — 스텝별 칸의 새 상태 두 가지 (B 방식: 어두운 칸 + 색 테두리)

"더비온 흐름" 묶음 칸 5개. 위 = 경마일에 2.0 로그인이 터진 순간, 아래 = 비경마일 평상시. 막대: 초록 = 정상 ms, 빨강 빗금 = 실패(지금 규칙 그대로), 회색 낮은 막대 = 앞 단계 실패로 확인 못 함, 빈 자리 + 작은 ○ = 분기 조건 불충족.

제 판단: "확인 못 함"(앞 단계 실패) = 실선 회색 테두리 + 흐린 글자, "분기 제외" = 점선 회색 테두리 + 값은 밝게(정상적인 상황이므로 읽히게). 둘 다 깜빡임·연속 횟수 없음. 기존 "확인 불가"(점검 자체가 멈춤)와는 문구를 다르게 둠. 화면 방식 A(배경색)·C(실패만 크게)도 같은 규칙 — A는 회색 배경, C는 작은 칸에 머묾.
