설정 화면 — 한 번 실행을 여러 칸이 나눠 보는 방식

같은 보드에 "더비온 흐름"(로그인 1회 → 5단계)을 스텝별 칸 5개로 만든 모습. 두 안 모두 기존 보드(칸마다 혼자 실행)는 그대로 열림. 마음에 드는 쪽을 눌러 주세요.

A

점검 묶음 상자 안에 칸들

시나리오·환경·점검 주기는 묶음에 한 번만. 칸은 묶음 안에서 "어느 스텝을 볼지"만 고른다. 칸 목록(오른쪽)도 묶음 단위로 들여쓰기.

환경: 운영
점검 주기: 10초

▸칸 22.0 로그인스텝: 더비온 2.0 로그인 · 제한 3초 · 조건 2

B

칸 목록은 지금처럼 평평하게 + 칸마다 "누구의 실행을 쓸지"

첫 칸이 실행을 맡고(시나리오·환경·주기), 나머지 칸은 "칸 1과 같은 실행 사용"을 골라 스텝만 정한다. 화면 구조 변화가 적다.

▸칸 11.0 로그인더비온 흐름 · 10초 · 스텝: 1.0 로그인 · 실행 담당

제 추천은 A: "로그인 한 번 = 묶음 하나"가 화면에 그대로 보이고, 칸 1을 지우면 나머지가 어떻게 되나 같은 B의 애매함이 없음. 단점은 설정 화면 구조가 지금보다 한 단계 깊어짐. 어느 안이든 칸 1개짜리 묶음 = 지금의 "혼자 실행" 칸과 같음.
