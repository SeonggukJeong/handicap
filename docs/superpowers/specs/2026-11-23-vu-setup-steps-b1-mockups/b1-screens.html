준비 스텝 B1 — 에디터 화면 목업

B1이 아웃라인과 Inspector에 더하는 것입니다. 색·글자 크기·간격은 실제 앱의 값이고, 준비 구획 상자와 행 모양은 A2 목업에서 승인된 그대로입니다. 노란 테두리 = B1에서 새로 생기는 조작부(실제 화면에는 테두리가 없습니다).

1. 준비 스텝이 하나도 없을 때

첫 준비 스텝을 만드는 길과 끌어 놓을 자리입니다. 세 안 가운데 하나를 고릅니다.

결정(사용자 2026-11-23): 다 채택 — 평소 숨김 + 아래 「+ 준비 스텝」 버튼 + http 스텝을 끄는 동안에만 맨 위에 놓을 자리. 「가」·「나」·「다-2」는 비교용으로 남긴 기각안입니다(다-2 기각 이유: 시나리오가 길면 놓을 자리가 한눈에 들어오지 않음). 장면 2–4는 그대로 승인. 나타나는 시점 변경(사용자 2026-11-23): 놓을 자리는 끌자마자가 아니라 포인터를 목록 맨 위로 가져갔을 때만 열리고, 내려오면 닫힙니다(끌자마자 열면 목록이 밀려 제자리에 놓아도 준비 스텝이 되고, 본 스텝끼리 순서 바꾸기도 달라짐). 모양은 이 목업 그대로.

가 빈 상자를 항상 보임

준비 스텝 — VU마다 한 번만 실행

스텝을 여기로 끌어 놓을 수도 있습니다.

본 스텝 — 반복 실행

⠿POST
토큰 발급${BASE_URL}/auth/token
⠿GET
주문 목록 조회${BASE_URL}/orders

눈에 가장 잘 띕니다. 준비가 필요 없는 시나리오에도 상자와 「본 스텝」 머리 줄이 늘 있습니다.

나 평소 숨김 — 아래 버튼만

⠿POST
토큰 발급${BASE_URL}/auth/token
⠿GET
주문 목록 조회${BASE_URL}/orders

지금 화면과 거의 같습니다. 첫 준비 스텝은 끌어서 만들 수 없고, 이 버튼이나 Inspector의 「준비 스텝으로 옮기기」로 만듭니다.

다 「나」 + 끄는 동안에만 놓을 자리

여기에 놓으면 준비 스텝이 됩니다
⠿POST
토큰 발급${BASE_URL}/auth/token
⠿POST
토큰 발급${BASE_URL}/auth/token
⠿GET
주문 목록 조회${BASE_URL}/orders

「토큰 발급」을 끄는 중인 모습입니다. 평소에는 「나」와 같고, http 스텝을 집어 목록 맨 위로 가져가면 맨 위에 점선 자리가 열립니다(이때 목록이 한 줄만큼 아래로 밀리고, 포인터가 내려가면 닫힙니다 — 위 결정 메모). 반복·조건·병렬을 집으면 열리지 않습니다.

기각안 다-2(2026-11-23) — 놓을 자리를 새로 만들지 않고, 아래 「+ 준비 스텝」 버튼이 끄는 동안 놓을 자리로 바뀌는 안. 구현 기준이 아닙니다.

다-2 평소 — 「나」와 같음

⠿POST
토큰 발급${BASE_URL}/auth/token
⠿GET
주문 목록 조회${BASE_URL}/orders

다-2 http 스텝을 끄는 중 — 버튼이 놓을 자리가 됨

⠿POST
토큰 발급${BASE_URL}/auth/token
⠿GET
주문 목록 조회${BASE_URL}/orders

목록은 움직이지 않습니다. 버튼 줄은 목록 스크롤 밖에 고정돼 있어 스텝이 많아도 늘 보입니다. 버튼 글자가 길어지며 버튼만 넓어집니다(줄이 꽉 차 있으면 버튼이 다음 줄로 넘어갈 수 있음).

다-2 버튼 위에 올렸을 때

⠿POST
토큰 발급${BASE_URL}/auth/token
⠿GET
주문 목록 조회${BASE_URL}/orders

놓으면 맨 위에 준비 상자가 생기고 그 스텝이 들어갑니다. 아쉬운 점: 준비 구획은 위에 생기는데 놓는 자리는 아래입니다.

2. 준비 스텝이 있을 때 — 손잡이와 추가 버튼

준비 행에도 끌기 손잡이(⠿)가 생기고, 상자 안 맨 아래에 추가 버튼이 붙습니다. 누르면 준비 구획 끝에 새 http 스텝이 생기고 선택됩니다. 세 안 모두 같습니다.

평소

준비 스텝 — VU마다 한 번만 실행

⠿POST
토큰 발급${BASE_URL}/auth/token
⠿GET
내 정보 확인${BASE_URL}/me

본 스텝 — 반복 실행

⠿GET
주문 목록 조회${BASE_URL}/orders
⠿POST
주문 생성${BASE_URL}/orders

준비 스텝이 있으면 아래 버튼 줄의 「+ 준비 스텝」은 내지 않습니다(상자 안 버튼 하나만). 나중에 준비 구획이 반복·조건을 받게 되면 상자 안 버튼 옆에 같은 모양으로 늘어납니다.

본 스텝을 준비 구획으로 끄는 중

준비 스텝 — VU마다 한 번만 실행

⠿POST
토큰 발급${BASE_URL}/auth/token
⠿GET
내 정보 확인${BASE_URL}/me

본 스텝 — 반복 실행

⠿GET
주문 목록 조회${BASE_URL}/orders
⠿GET
주문 목록 조회${BASE_URL}/orders
⠿POST
주문 생성${BASE_URL}/orders

놓일 자리에 파란 줄(지금 구획 사이 끌기에 쓰는 표시와 같음), 받는 상자에 테두리 강조. 반대 방향(준비 → 본 스텝, 반복·조건 안 포함)도 같은 표시입니다.

반복을 끄는 중 — 준비 구획은 받지 않음

준비 스텝 — VU마다 한 번만 실행

⠿POST
토큰 발급${BASE_URL}/auth/token

본 스텝 — 반복 실행

⠿반복
주문 3회3회 반복
⠿POST
주문 생성${BASE_URL}/orders

http가 아닌 스텝을 집으면 준비 상자가 흐려지고 놓을 자리가 생기지 않습니다(지금 「놓을 수 없는 자리」와 같은 방식 — 놓아도 아무 일도 일어나지 않음).

3. Inspector — 준비 스텝의 ↑↓

준비 스텝을 고르면 본 스텝과 같은 자리에 ↑↓가 나옵니다. 준비 구획 안에서만 움직이고, 맨 위·맨 아래에서는 꺼집니다. 「본 스텝으로 옮기기」 줄은 A2 그대로입니다.

4. 새 시나리오 갤러리 — 「로그인 흐름」을 고른 직후

지금은 본 스텝 2개로 시작합니다. B1부터는 「로그인」이 준비 스텝, 「내 정보 조회」가 본 스텝으로 시작합니다. 갤러리 카드의 이름·설명은 바꾸지 않습니다.

⠿GET
내 정보 조회${BASE_URL}/me
