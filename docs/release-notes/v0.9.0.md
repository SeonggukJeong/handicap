## 하이라이트

### 체크박스·좌석 선택 같은 배열 값을 반복마다 랜덤으로 만듭니다 (선택 배열)
변수 패널에 다섯 번째 생성 변수 **선택 배열**이 추가됐습니다. 길이 N짜리 배열에서 선택 개수 최소~최대만큼의 자리를 반복마다 무작위로 골라 "선택 값"을, 나머지 자리엔 "나머지 값"을 채웁니다. 요청 바디에 `"flags": "{{flags:json}}"`처럼 쓰면 문자열이 아니라 진짜 JSON 배열(`[false,true,false,…]`)이 나갑니다.

- **선택될 수 있는 자리 지정**: 품절 좌석·비활성 옵션처럼 절대 선택되면 안 되는 자리가 있으면 `1-5, 8`처럼 범위로 쓰거나 편집 팝업의 칸을 클릭해 고릅니다. 텍스트와 칸 그리드는 항상 같은 상태로 보입니다(길이 1000까지).
- **값 형식**: 기본 `true / false` 외에 `"True" / "False"`·`1 / 0`·`"Y" / "N"` 프리셋과 직접 입력(`null` 포함 JSON 스칼라)을 지원합니다. 숫자는 숫자로, 문자열은 문자열로 그대로 나가고, 팝업의 미리보기와 실제 전송 값이 일치합니다.
- **안전한 편집**: 팝업 안의 편집은 `적용`을 누르기 전까지 시나리오에 반영되지 않으며, 후보 0개·최소>최대 같은 잘못된 설정은 적용 자체가 막힙니다.
- **나중에 선언해도 됩니다**: 바디에 `{{flags:json}}`을 먼저 써 두면 미정의 변수 행에 **배열로 추가** 버튼이 떠서 바로 선택 배열로 선언할 수 있습니다.

### 응답의 base64·JWT 값을 풀어서 추출합니다
값 추출에 **디코딩** 옵션(`base64` / `jwt`)과 **claim**(JSONPath)이 추가됐습니다. 응답 본문·헤더·쿠키에서 꺼낸 base64(표준·URL-safe, 패딩 유무 자동 판별) 문자열을 풀거나, JWT(`Bearer ` 접두 자동 제거)의 페이로드에서 `$.sub` 같은 클레임만 골라 다음 요청에 쓸 수 있습니다.

- 실패하면 "어느 변수가, 왜(base64 아님 · JWT 형식 아님 · claim 없음 …)" 실패했는지 고정 문구로 알려 주며, 토큰이나 디코딩된 값은 오류 메시지에 노출되지 않습니다.

### Run에 이름표를 붙여 찾고 비교합니다
run마다 **라벨**(예: "배포 전 기준선", "캐시 ON")을 붙일 수 있습니다. 실행할 때 지정하거나 run 상세와 목록에서 나중에 고칠 수 있고, 스케줄이 발사한 run에는 스케줄 이름이 자동 라벨로 붙습니다.

- 라벨이 없으면 ID 끝 6자리(`#a1b2c3`)로 표시됩니다. run 상세에는 설정 요약 한 줄도 함께 보입니다.
- run 목록에서 라벨·ID로 검색하고, 비교 화면 헤더와 차트 범례, XLSX 내보내기(Runs 시트)에도 라벨이 표시됩니다.

### 그 밖의 개선
- 미리 실행 결과의 긴 추출값 칩이 상자 밖으로 넘치던 문제를 고쳤습니다.
- CI 빌드 액션을 Node 24 기반으로 올려 deprecation 경고를 해소했습니다.

## 참고

- 코드 서명이 **없는** 배포라 Windows SmartScreen이 경고를 띄웁니다. 정상적인 경고이며 **"추가 정보" → "실행"** 으로 진행합니다. macOS는 Gatekeeper가 차단할 수 있습니다 — 우클릭 → 열기(또는 `xattr -dr com.apple.quarantine`)로 실행합니다.
- DB 마이그레이션(runs 라벨 컬럼)은 시작 시 자동 적용됩니다. 기존 시나리오·run은 그대로 동작합니다.
- 변경 내역 전체: [`v0.8.0...v0.9.0`](https://github.com/SeonggukJeong/handicap/compare/v0.8.0...v0.9.0), 기능별 상세는 [`docs/build-log.md`](https://github.com/SeonggukJeong/handicap/blob/master/docs/build-log.md).
