## 하이라이트

### 터미널 모니터 `handicap-tui` — 보는 것에서 고치는 것까지

v0.13.0에서 처음 배포한 터미널 모니터가 이제 **터미널 안에서 원인을 보고, 칸 설정을 고치고, 바로 다시 점검**할 수 있습니다. GUI가 없는 모니터 PC에서도 보드를 손볼 수 있습니다.

- **`e` 오류 보기**: 선택한 칸의 실패 목록 → `Enter`로 그 회차 자세히(실패 사유·판정 상세·스텝 표) → `Enter`로 스텝의 요청·응답(JSON 들여쓰기, 요청 본문은 기본 가림, 인증 값은 가림). `←` `→`로 같은 기록의 앞뒤 스텝으로 넘어갑니다.
- **`Enter` 칸 설정 고치기**: 번호나 `↑↓`로 항목을 골라 고치면 서버에 바로 반영되고 **보드 파일에도 저장**됩니다(저장 전 `.bak`, 처음 한 번 `.orig.bak` 백업). 밖에서 파일이 바뀌었으면 덮어쓰지 않습니다. 환경 변수 값(기본 가림)·시나리오 고정 변수도 한 줄씩 고칠 수 있고, 붙여넣기와 마우스도 됩니다.
- **`r` 지금 점검**: 주기를 기다리지 않고 선택 칸을 실제로 한 번 점검합니다(막대·기록에 그대로 남음). 칸 설정 화면에서 누르면 점검이 끝난 뒤 그 회차의 자세히 화면이 열려, 방금 고친 설정이 어떻게 판정되는지 바로 볼 수 있습니다. 같은 칸은 1초에 한 번까지, 점검 중에 누른 것은 무시합니다.
- **`a` 응답에서 값 골라 조건·표시 추가**: 요청·응답 화면에서 `a`를 누르면 그 응답의 값 목록(응답 코드·헤더·본문 값, 문자열로 감싼 JSON은 풀어서)이 열립니다. 값을 골라 **조건으로 추가**(받은 값으로 미리 채워진 조건 칸)하거나 **화면에 추가**할 수 있습니다. 칸 설정 11·12번에서 `a`를 누르면 지금 점검 뒤 바로 값 목록까지 갑니다. GUI의 미리 실행 결과에서 `+ 추가`한 것과 같은 조건이 저장됩니다.
- **막대 아래 시각 줄 중간 눈금**: 자리가 있으면 양 끝 사이에도 시각을 고른 간격으로 보여 주고, `▲`가 그 시각의 막대를 가리킵니다.

### 측정결과 보고서 인쇄 — 다듬기

- Windows의 넓은 한글 글꼴에서 종합 판정 상자 문구가 단어 중간에 줄바꿈되던 문제를 고쳤습니다.
- 응답 코드가 1~2종뿐일 때 단계 표 머리 줄이 길게 늘어지던 문제를 고쳤습니다.
- 오류 집계 문구("포함/제외")와 경고 문장의 조사를 자연스럽게 다듬었습니다.

## 참고

- 코드 서명이 **없는** 배포라 Windows SmartScreen이 경고를 띄웁니다. **"추가 정보" → "실행"** 으로 진행합니다. macOS는 Gatekeeper가 차단할 수 있습니다 — 우클릭 → 열기(또는 `xattr -dr com.apple.quarantine`)로 실행합니다.
- **터미널 모니터에서 고친 설정은 보드 파일에 저장됩니다.** 조건의 비교값·환경 변수 값도 파일에 들어가니, 파일을 다른 곳에 옮기거나 공유할 때 주의하세요. 응답에서 고른 짧은 값(40자 이하)은 비교값으로 미리 채워지므로, 세션 id·토큰 같은 값이면 저장 전에 규칙을 바꾸거나 지우세요(GUI와 같은 동작). 보안 전제(전용 단일 사용자 모니터 PC)는 그대로입니다 — 매뉴얼 §9.
- **Windows 터미널 모니터의 알려진 제한**은 v0.13.0과 같습니다(매뉴얼 §1-1): `HOME`이 없어 로그·설정 기억이 기본으로 꺼짐(`setx HOME "%USERPROFILE%"`로 켬), 창의 X 버튼으로 닫으면 `%TEMP%\handicap-tui-*` 임시 DB가 남을 수 있음(`q` → `y`로 종료).
- 이번 릴리즈에는 DB 마이그레이션이 없습니다. 기존 시나리오·run·모니터 보드는 그대로 동작합니다. 컨트롤러에는 지금 점검용 API(`POST /api/monitor-boards/{id}/panels/{panel_id}/check-now`)가 추가됐습니다.
- LAN 분산 워커·Kubernetes를 쓰는 경우 컨트롤러와 워커를 함께 0.14.0으로 올리는 것을 권장합니다.
- 변경 내역 전체: [`v0.13.0...v0.14.0`](https://github.com/SeonggukJeong/handicap/compare/v0.13.0...v0.14.0), 기능별 상세는 [`docs/build-log.md`](https://github.com/SeonggukJeong/handicap/blob/master/docs/build-log.md).
