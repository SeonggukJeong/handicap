## 하이라이트

### 실행 중에도 부하 궤적이 보입니다
run 진행 중 Run 상세 페이지에 **초당 요청 수·초당 에러** 시계열 차트가 라이브로 표시됩니다("라이브 궤적"). 계속 지켜보지 않아도, 자리를 비웠다 돌아와도 시작부터 지금까지의 전체 궤적(ramp-up 상승·정체·급락)이 그래프로 남아 있습니다.

- 에러가 **언제부터** 나기 시작했는지를 run 종료 전에 보고, 계속 둘지 즉시 중단할지 그 자리에서 결정할 수 있습니다.
- 이미 1초마다 수집·조회하던 데이터를 그대로 표시하는 것이라 서버 부하가 늘지 않고, 종료 후 리포트 시계열과 **같은 1초 단위 데이터 기준**이라 라이브에서 보던 모양 그대로 사후 분석으로 이어집니다.
- 최신 1초는 집계가 끝난 뒤에 그리므로 그래프가 실제보다 약 1초 늦게 따라옵니다(부분 집계값이 순간적으로 낮게 보이는 왜곡을 막기 위한 의도된 동작입니다).

### 요청이 서버에 닿기 전에 실패한 이유를 분류합니다
응답을 받지 못한 전송 단계 실패가 리포트에 **8종으로 분류**되어 표로 표시됩니다: 연결 거부 · 연결 리셋 · 연결 타임아웃 · 응답 타임아웃 · DNS · TLS · 로컬 포트 고갈 · 기타.

- "에러 N건"에서 멈추지 않고 — 대상 서버가 내려갔는지(연결 거부), 네트워크·방화벽 문제인지(타임아웃), 부하를 거는 쪽 머신의 한계인지(로컬 포트 고갈)를 리포트에서 바로 구분합니다.

### 실패가 "언제부터" 시작됐는지 짚어줍니다
리포트 인사이트가 실패 시작 시점과 원인 후보를 문장으로 제시합니다 — "약 13초 지점까지는 정상이더니, 그 뒤로 실패가 급증했어요" 같은 형태로, 어떤 실패 종류가 함께 늘었는지까지 붙습니다.

### 연결 수립에만 별도 타임아웃을 걸 수 있습니다
전체 응답 타임아웃과 별개로 **연결 타임아웃**(연결 수립 단계 전용)을 선택적으로 설정합니다. 실행 대화상자와 스케줄 폼 양쪽에서 입력·해제할 수 있고, 적용된 값은 run 상세와 리포트에 표시되어 "이 시험이 어떤 타임아웃 설정으로 돌았나"를 사후에도 확인합니다.

- 내려간 서버는 짧은 연결 타임아웃으로 빠르게 끊고, 느린 응답은 전체 타임아웃으로 따로 관리하는 구성이 가능해집니다.
- 설정하지 않으면 기존과 완전히 동일하게 동작합니다.

### 화면 낭독(스크린리더) 접근성 개선 묶음
- 실행 대화상자·스케줄 폼의 입력 힌트(타임아웃·동시 요청 상한·think time 등)가 스크린리더에 읽히도록 연결됐습니다. 입력 오류가 있으면 오류를 먼저 읽습니다.
- 검증 배너의 낭독 순서(제목→설명→버튼), run 상세 배지의 heading 분리, 에디터 접기 토글의 대상 연결, 버전 표시 명도 대비(AA) 등 소형 개선 다수.

### 버전을 어디서나 확인할 수 있습니다
UI 헤더에 버전 배지가 붙고, `controller --version`·`GET /api/version`으로도 확인됩니다. 문제 보고 시 "어느 버전에서 났나요?"에 바로 답할 수 있습니다.

## 다운로드

| 환경 | 파일 | 비고 |
|---|---|---|
| Windows (설치) | `Handicap_0.8.0_x64-setup.exe` | 권장. 컨트롤러·워커·UI·DB 내장 |
| Windows (설치, MSI) | `Handicap_0.8.0_x64_en-US.msi` | 사내 배포 도구·그룹 정책으로 일괄 설치할 때 |
| Windows (포터블) | `Handicap_0.8.0_x64-portable.exe` | 설치 없이 exe 한 파일 |
| macOS (Apple Silicon) | `Handicap_0.8.0_aarch64.dmg` | 서명·공증 없음 — 우클릭 → 열기로 실행 |
| macOS (Intel) | `Handicap_0.8.0_x64.dmg` | 서명·공증 없음 — 우클릭 → 열기로 실행 |

Linux 서버·폐쇄망·LAN 분산 워커·Kubernetes 설치는 [README](https://github.com/SeonggukJeong/handicap)의 **"시작하기 — 환경별 설치 절차"** 절을 참고하세요.

## 참고

- 코드 서명이 **없는** 배포라 Windows SmartScreen이 경고를 띄웁니다. 정상적인 경고이며 **"추가 정보" → "실행"** 으로 진행합니다. macOS는 Gatekeeper가 차단할 수 있습니다 — 우클릭 → 열기(또는 `xattr -dr com.apple.quarantine`)로 실행합니다.
- v0.7.0 이후 157개 커밋. 변경 내역 전체: [`v0.7.0...v0.8.0`](https://github.com/SeonggukJeong/handicap/compare/v0.7.0...v0.8.0), 기능별 상세는 [`docs/build-log.md`](https://github.com/SeonggukJeong/handicap/blob/master/docs/build-log.md).
