## 하이라이트

### 터미널 모니터 `handicap-tui` (신규 — Ubuntu·Windows)

웹 브라우저를 새로 깔기 어려운 모니터 PC에서 **운영 모니터 보드를 터미널 화면으로** 계속 띄워 둘 수 있습니다. GUI에서 보드를 **내보내기**한 json 파일 하나를 넘겨 실행하면, 프로그램 안에 든 컨트롤러가 보드를 가져와 점검을 시작합니다. 별도 서버·브라우저는 필요 없습니다.

```sh
handicap-tui /home/ops/board.json          # 화면 띄우기
handicap-tui --check /home/ops/board.json  # 모든 칸을 한 번 점검하고 결과만 출력
```

- **멀리서도 읽히는 화면**: 칸 높이를 채우는 여러 줄 막대(높이 = 응답 시간)와 기준선, 칸이 넉넉하면 여러 줄 높이의 큰 응답 시간 숫자, 느림·실패 칸 바탕색. 글자 크기 단계는 보드 설정과 칸 크기로만 정해져 응답 시간이 바뀌어도 들쑥날쑥하지 않습니다.
- **막대 아래 시각 줄**: 자리를 비운 사이 지나간 실패가 몇 시쯤이었는지 읽을 수 있습니다.
- 방향키·`h` `j` `k` `l`로 칸 선택, `Tab`으로 보드 전환, `?` 도움말, `b` 테두리 모양 바꾸기, `q`→`y` 종료. 한글 입력기나 Caps Lock이 켜져 있어도 같은 키로 동작합니다. 마우스로 칸을 누를 수도 있습니다.
- **Ubuntu**: glibc 2.27 이하 심볼만 쓰는 바이너리라 Ubuntu 18.04·19.04 같은 구형 PC에서도 추가 라이브러리 없이 돕니다. 로그인 시 전체화면 자동 시작 방법은 함께 든 매뉴얼(`tui-monitor.md`) §2를 보세요.
- **Windows**: Windows Terminal에서 실행하세요. 이번이 첫 배포라 실제 Windows PC에서는 아직 확인 전이며(빌드와 `--check` 점검만 자동 확인), 알려진 제한이 있습니다 — 아래 참고.

### 측정결과 보고서 인쇄 (A4)

끝난 run 리포트에서 **보고서 인쇄**를 누르면 A4로 인쇄하거나 PDF로 저장할 수 있는 측정결과 보고서가 열립니다.

- **표준판**(전체)과 **요약판**(1장에 맞춤) 두 종류. 요약판이 넘치면 덜 중요한 부분부터 줄이고 "표준판에 전체"라고 알려 줍니다.
- 판정 상자·핵심 지표 4칸·그 밖의 기준, 측정 조건, 시간 흐름 차트와 자동 요약 문장, 단계 × 응답 코드 표, 용어 설명이 들어갑니다.
- 대상 주소에 섞인 계정·비밀번호·토큰은 보고서에 찍지 않고, 환경 변수는 개수만 표시합니다.

### 운영 모니터 — 감싼 JSON을 안쪽 필드까지 풀기

`{"code":1,"data":"{\"id\":7}"}`처럼 **응답 안쪽 필드가 문자열로 감싼 JSON**이어도 `$.data.id`로 조건과 화면 표시 값을 걸 수 있습니다. 미리 실행·기록 창의 값 트리도 안쪽까지 풀어 보여 줍니다. 지금 찾히는 경로의 값은 그대로이고, 원래 값에서 못 찾을 때만 풀어서 찾습니다.

- **동작 변경**: 성공 조건 **"값 있음"**은 문자열로 감싼 빈 배열·객체(`"[]"`·`"{}"`)를 비어 있음으로 판정합니다. 이런 필드에 "값 있음"을 걸어 둔 칸은 정상 → 실패로 바뀔 수 있습니다.

## 참고

- 코드 서명이 **없는** 배포라 Windows SmartScreen이 경고를 띄웁니다. **"추가 정보" → "실행"** 으로 진행합니다. macOS는 Gatekeeper가 차단할 수 있습니다 — 우클릭 → 열기(또는 `xattr -dr com.apple.quarantine`)로 실행합니다.
- **터미널 모니터의 보안 전제**: 안에 든 컨트롤러는 이 PC 안에서만 접속을 받지만 인증이 없습니다. **전용 단일 사용자 모니터 PC**에서 쓰고, 그 PC에서 웹 브라우저로 인터넷을 보지 마세요. 보드 json에는 환경 값이 들어 있으니 파일 보관에 주의하세요(매뉴얼 §9).
- **Windows 터미널 모니터의 알려진 제한** (매뉴얼 §1-1, 후속 수정 예정):
  - 로그와 `b` 테두리 선택 기억이 기본으로 꺼집니다(Windows에는 `HOME` 환경 변수가 없음). `setx HOME "%USERPROFILE%"`를 한 번 실행하면 켜집니다.
  - 콘솔 창의 X 버튼으로 닫으면 임시 DB(환경 값 포함)가 `%TEMP%\handicap-tui-*`에 남을 수 있고, 다음 시작 때 자동으로 지워지지 않습니다. `q` → `y`로 종료하거나, 남은 폴더를 직접 지우세요.
- 이번 릴리즈에는 DB 마이그레이션이 없습니다. 기존 시나리오·run·모니터 보드는 그대로 동작합니다.
- LAN 분산 워커·Kubernetes를 쓰는 경우 컨트롤러와 워커를 함께 0.13.0으로 올리는 것을 권장합니다.
- 변경 내역 전체: [`v0.12.0...v0.13.0`](https://github.com/SeonggukJeong/handicap/compare/v0.12.0...v0.13.0), 기능별 상세는 [`docs/build-log.md`](https://github.com/SeonggukJeong/handicap/blob/master/docs/build-log.md).
