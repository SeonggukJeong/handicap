## 하이라이트

### Ubuntu 데스크톱 앱

Ubuntu 22.04 이상 x86_64에서 실행할 수 있는 GUI 패키지를 추가했습니다.

- `.deb` 패키지를 설치하면 앱 목록에서 Handicap을 실행할 수 있습니다.
- `.AppImage` 파일도 함께 제공해 설치 없이 실행할 수 있습니다.
- 앱 안에 컨트롤러·워커·UI·DB가 포함됩니다.

### 오류 수정

- Open-loop 곡선 부하에서 목표 도착률을 누적 도착 시각으로 계산해 저레이트 구간이 무부하로 빠지던 문제를 수정했습니다.
- 곡선 부하 시작 시 첫 도착 지연을 startup grace에 반영했습니다.
- 선택 배열 편집 팝업의 요청마다 새로 뽑기 설정을 편집·저장할 수 있도록 수정했습니다.
- 도움말 팝오버가 화면 가장자리와 스크롤 영역에서 잘리거나 위치를 잘못 계산하던 문제를 수정했습니다.

## 다운로드

| 환경 | 파일 | 비고 |
|---|---|---|
| Ubuntu 22.04+ (설치) | `Handicap_0.10.1_amd64.deb` | App Center에서 설치하거나 `apt install` 사용 |
| Ubuntu 22.04+ (설치 없이) | `Handicap_0.10.1_amd64.AppImage` | 실행 권한 필요, FUSE 런타임 필요 |
| Windows (설치) | `Handicap_0.10.1_x64-setup.exe` | NSIS 설치 프로그램 |
| Windows (설치, MSI) | `Handicap_0.10.1_x64_en-US.msi` | 사내 배포용 |
| Windows (포터블) | `Handicap_0.10.1_x64-portable.exe` | 설치 없이 실행 |
| macOS (Apple Silicon) | `Handicap_0.10.1_aarch64.dmg` | 서명·공증 없음 — 우클릭 → 열기로 실행 |
| macOS (Intel) | `Handicap_0.10.1_x64.dmg` | 서명·공증 없음 — 우클릭 → 열기로 실행 |

Linux 서버·폐쇄망·LAN 분산 워커·Kubernetes 설치는 [README](https://github.com/SeonggukJeong/handicap)의 **"시작하기 — 환경별 설치 절차"** 절을 참고하세요.

## 참고

- Windows SmartScreen 및 macOS Gatekeeper 경고가 나타날 수 있습니다. 코드 서명·공증이 없는 배포입니다.
- LAN 분산 워커나 Kubernetes에서 컨트롤러와 워커를 따로 쓰는 경우 두 구성요소를 모두 0.10.1로 올리세요.
- DB 마이그레이션은 없습니다. 기존 시나리오와 실행 기록은 그대로 유지됩니다.
- 변경 내역: [`v0.10.0...v0.10.1`](https://github.com/SeonggukJeong/handicap/compare/v0.10.0...v0.10.1).
