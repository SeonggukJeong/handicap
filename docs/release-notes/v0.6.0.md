> 이번 릴리즈는 **Windows 전용**입니다 — macOS `.dmg`는 다음 릴리즈(v0.7.0)부터 제공합니다.

## 하이라이트

### 실행 전에 시나리오 신뢰도를 점검합니다
부하를 걸기 전에 "요청은 다 나가는데 아무것도 검증하지 않는 시험"을 잡아냅니다. 시나리오 편집 화면에 신뢰도 등급(**양호 / 보완 필요 / 취약**)이 상시 표시되고, 눌러 보면 무엇이 문제인지와 고칠 위치가 나옵니다.

- 점검 3종: 응답 검증(assert)이 없는 요청 · 정의되지 않은 변수 참조 · 끊어진 추출(extract) 체인. 검증이 빠진 스텝은 **이름을 눌러 바로 이동**하고, 변수 문제는 변수 패널로 연결됩니다.
- 실행 대화상자에는 등급이 `양호`가 **아닐 때만** 한 줄이 붙습니다 — 멀쩡한 시나리오를 실행할 때는 화면에 아무것도 늘지 않습니다.
- 시험 실행으로 실제 돌려 봤는지는 `(미확인)` 접미로 따로 표시됩니다(등급 자체에는 영향을 주지 않습니다). URL·헤더·바디처럼 실행에 쓰이는 부분을 고치면 다시 `(미확인)`으로 돌아갑니다.

### 리포트가 "이 결과를 믿어도 되나"를 먼저 말합니다
run이 `완료`로 끝나고 SLO도 초록이어도, 시험 자체가 아무것도 증명하지 못한 경우가 있습니다. 이제 리포트 헤더와 상단에 **시험 유효성** 표시와 그 사유가 붙습니다.

- 잡는 경우: 요청이 0건 · 전송 단계 오류가 과다 · HTTP 오류가 실패로 집계되지 않음 · 응답을 검증하는 수단(assert·SLO)이 전무 · 설정한 부하가 실제로 나가지 않음.
- run 상태와 SLO 합격/불합격 판정 자체는 바뀌지 않습니다(경고만 추가). 단, 시험 유효성이 의심스러우면 헤드라인을 "합격" 초록으로 칠하지 않습니다.

### 변수 값을 실행 시점에 만들 수 있습니다
변수 값으로 고정 문자열 대신 **생성기**를 고를 수 있습니다 — 날짜(오늘 ±N일, 형식·타임존 지정), 랜덤 정수(범위·간격), UUID, 랜덤 문자열(길이).

- 값은 **반복이 시작될 때 한 번** 만들어져 그 반복의 모든 스텝이 같은 값을 씁니다 — 주문번호를 만들어 등록하고 곧바로 조회하는 흐름에 그대로 쓸 수 있습니다.
- 쓰는 법은 기존과 같은 `{{변수명}}`이고, 변수 패널과 YAML 양쪽에서 편집됩니다.

### 생성 변수가 어떤 값이 될지 미리 보여줍니다
생성 변수마다 실제로 만들어질 값의 예시가 함께 표시됩니다. 날짜 형식을 잘못 썼는지 실행 전에 알 수 있습니다.

- 예시는 검색·화면 갱신에도 바뀌지 않고 **↻(다시 뽑기)** 를 눌렀을 때만 다시 추첨됩니다. 입력 중에도 칸을 벗어나기 전에 바로 반영됩니다.
- 길이·간격·최소/최대에 잘못된 값을 넣으면 그 자리에서 무엇이 잘못됐는지 알려주고, 입력 자체에 상·하한이 걸립니다.

### 시나리오에 팀 공유 메모를 남깁니다
시나리오 수정 화면 맨 위에 메모 영역이 생겼습니다. "이 시나리오는 스테이징 전용", "결제 스텝은 QA 전용 계정으로만" 같은 맥락을 시나리오와 같은 자리에 보관합니다.

- 그 자리에서 바로 편집하고, 접어 두면 접힌 상태가 유지됩니다(접힌 동안은 첫 줄만 미리보기).
- 메모는 시나리오 YAML에 들어가므로 내보내기·가져오기로 함께 옮겨지고, **실행에는 아무 영향이 없습니다.**

### 대기 시간 범위를 올릴 때 값이 되돌아가던 문제를 고쳤습니다
최소/최대 대기 시간을 `200/500`에서 `1000/2000`으로 올리면 `200–2000`이 저장되던 버그입니다 — 최소 칸에서 최대 칸으로 넘어가는 순간의 중간 상태(`1000/500`)가 잘못된 범위로 판정돼 되돌려졌습니다.

- 값을 **내릴 때는 정상**이라 "가끔 값이 안 먹는다"로만 보이던 종류의 결함입니다. 이제 최소·최대 짝을 실제로 벗어날 때만 저장됩니다.
- 대기 시간을 입력하는 **네 곳 모두**에 적용되고, 대화상자를 `ESC`로 닫아도 방금 입력한 값이 유지됩니다(최소 > 최대처럼 어긋난 값은 이전 값으로 되돌아갑니다).
