5. 용어 풀이

  • 처리량: 1초에 처리한 요청 수
  • 평균 응답 시간: 응답까지 걸린 시간의 평균
  • 95% 응답 시간: 요청의 95%가 이 시간 안에 응답한 기준선
  • 오류율: 도구가 오류로 판정한 요청의 비율
  • 2xx(성공 계열): 서버가 처리했다는 응답. 검사가 다른 코드를 기대하면 오류일 수 있음
  • 404: 없는 주소
  • 503: 서버가 바쁨
  • 응답 받은 뒤 실패: 응답은 받았지만 값 꺼내기나 본문 읽기에 실패함
  • 검사 없음(제외): 응답 코드 검사가 없어 오류에서 제외된 응답
